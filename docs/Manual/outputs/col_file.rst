The real name of the **COL** files is **XX.COL**, with **XX** the 
symbol of the element (e.g., H, Mg, Ca, etc.).

For each pair of terms, it first indicates if a collisional
transition has been inputed and then, for each pair of levels
within the terms, it indicates if there is a level to level
transition and, if there is, if it is allowed or forbidden.

::

  Information about the collisional rates
 
  Yes rate from term    2 to term    1
  Allowed rate from level    2 to level    1
  Allowed rate from level    3 to level    1
     
  No rate from term    3 to term    1
  Forbidden rate from level    4 to level    1
  Forbidden rate from level    5 to level    1
     
  Yes rate from term    3 to term    2
  Forbidden rate from level    4 to level    2
  Allowed rate from level    4 to level    3
  Allowed rate from level    5 to level    2
  Allowed rate from level    5 to level    3
