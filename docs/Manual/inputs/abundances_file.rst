The format of the abundance file is the following:

1. An integer with the number of elements in the file.
2. For each included element

    * The index of the element (atomic number).
    * The abundance for the element (12 + log\ :sub:`10`\ (N/N\ :sub:`H`)).

.. code-block:: none
    
   |-------------------------------+------------------------------------------------------|
   |  1 * (int)                    | Number of elements in the file                       |
   |--------------------------------------------------------------------------------------|
   | For each element              |                                                      |   
   |                               |                                                      |   
   |   1 * (int)                   | Atomic number                                        |   
   |   1 * (double)                | Abundance                                            |   
   |                               |                                                      |   
   |--------------------------------------------------------------------------------------|
